## The headlines
1. **Funding:** the $50k–$5M range best matches **Solana Ventures**. Colosseum's hackathons are a backup route to $250k. Get the contact's name and fund first.
2. **Cards:** this is where Solana fits. Cards cost fractions of a cent each, a wallet is made silently at sign-up, and Nekta pays all fees. Say "cards" and "passes", never "NFTs".
3. **Ticketing:** don't compete on issuing tickets. That's a fight over venue contracts and cash advances. Build the fan loyalty layer on top instead.
4. **Audio:** don't put dubs on-chain, because permanent public storage can't be deleted or taken down. Use the dub card as an access key, with watermarked streaming of each holder's copy, so leaks are traceable and access can be pulled.
